# Python Def Function

This repository contains my Python program that demonstrates the use of a def function.

The program uses a function called `calculate_total` to calculate the total cost of food based on its price and quantity.

The function is called using `calculate_total(50, 3)`, which calculates 50 pesos multiplied by 3 items, giving a total of 150 pesos.

- `def_activity.py` - contains the Python program that demonstrates the use of a def function.
